## 자료를 읽는 기준

- 개인 역할은 기존 발표자료·제안서 또는 이번 제출 신청서에 기록된 범위로 작성했습니다.
- 청주 안심동선은 **기획·설계 제안**입니다. 예시 위험점수와 예산은 실제 분석·운영 실적이 아닙니다.
- AgentBridge의 신청 분야와 팀 전체 구현을 구분했습니다. 세부 기능별 개인 작성자는 제출 신청서만으로 확정하지 않았습니다.
- AI 도구를 활용한 학습 프로젝트는 해당 활용 범위를 개인 페이지와 원본 저장소에 밝혔습니다.
