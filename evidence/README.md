## 작성 기준

개인 개발 역량·프로젝트 경험·활동 이력이 드러나도록 개인 페이지를 구성했습니다. 수상·자격증·사용자 수·속도 개선 수치를 근거 없이 추가하지 않았습니다. 팀 공동 산출물과 개인 역할은 구분했습니다.

이번 제출 신청서의 역할은 송지율 UI/UX, 김건우 AI·SW, 송성재 UI/UX, 황재찬 AI·SW입니다. 이전 대회의 팀 역할을 이번 AgentBridge의 세부 분담으로 옮겨 쓰지 않았습니다.

현재 김건우·송성재의 개인 자료는 청주 안심동선의 설계 제안 역할과 AgentBridge 신청 분야까지 확인됩니다. 개인 코드·디자인 원본·추가 활동 이력의 확인 범위는 이 자료에서 확장하지 않았습니다.
