코드 해설 ② — 메인 감지 루프

여러 물체를 동시에 잡아내는 핵심 반복문 · 담당: 송지율

SOURCE CODE

results = model(frame,
    imgsz=IMGSZ,
    verbose=False)[0]

for box in results.boxes:
    cls_name = model.names[
        int(box.cls[0])]
    if cls_name in EXCLUDE:
        continue

    x1,y1,x2,y2 = map(int,
        box.xyxy[0])
    conf = float(box.conf[0])*100
    trash_type = TRASH_MAP.get(
        cls_name, cls_name)

# 코드 주석 · 해설

model(frame, ...)[0]로 프레임 한 장을 추론해 결과 객체 하나를 받는다
results.boxes를 for문으로 도는 것만으로 다중 인식이 된다 — 물체가 여러 개면 반복 횟수만큼 박스가 여러 개 그려진다. 따로 켜야 하는 기능이 아니다
box.xyxy[0]에서 좌표 4개를 꺼내 정수로 바꾸고, box.conf[0]에 100을 곱해 퍼센트 신뢰도로 변환한다
TRASH_MAP.get()으로 매핑한 분리배출 종류와 신뢰도를 함께 문자열로 만들어 물체 바로 위에 표시한다
이 다섯 줄이 매 프레임 반복되면서, 박스가 물체를 실시간으로 따라다니는 것처럼 보인다

## 원본 13쪽

CHAPTER 08 · 한계와 배운 점

GOAT

한계와 배운 점

사전학습 모델로 짧게 만든 만큼, 안 되는 것도 분명했다

한계

yolov8n은 COCO 데이터로 학습된 범용 모델이라, 실제로 자주 버리는 물건(비닐봉지, 종이컵, 찌그러진 캔 등)의 전용 클래스가 없다
그래서 bottle처럼 COCO에 있는 라벨은 잘 잡지만, COCO에 없는 물건은 아예 인식하지 못하거나 엉뚱한 라벨로 잡힌다
하드웨어(STM32 + 서보모터) 연동은 이번 산출물에 포함하지 못했다 — 인식 결과를 화면에 보여주는 단계까지만 구현했다

배운 점

처음부터 데이터를 모아 새 모델을 학습시키지 않아도, 사전학습 모델과 매핑 규칙만으로 짧은 시간 안에 실제로 동작하는 결과물을 만들 수 있었다
처리 속도는 모델 성능뿐 아니라 입력 이미지 크기, 카메라 초기화 방식 같은 주변 설정에도 크게 좌우된다는 것을 체감했다
for문 하나로 여러 물체를 동시에 처리하는 구조가, 예외 케이스(사람 제외 등)를 조건문 한 줄로 붙이기 쉽게 만들어준다는 것을 배웠다
