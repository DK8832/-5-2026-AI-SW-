# 황재찬 · 개인 개발 포트폴리오

인천전자마이스터고등학교 인공지능전자과 2학년 · innovation 팀원

영상 인식 프로그램의 실행 환경을 조정하고, 화면에 결과가 안정적으로 나타나도록 디버깅한 경험이 있습니다. 데이터 서비스 기획에서는 지도와 정보 표시 구조를 다뤘습니다. 이번 AgentBridge의 신청 분야는 AI·SW입니다.

## 1. AI 분리배출 도우미 · 실행 환경과 입력 크기 조정

**활동:** 2026 SW미래채움 AI·SW 고교 챌린지 피지컬 AI 프로젝트. 당시 GOAT 팀의 노문선·송지율·황재찬이 함께한 소프트웨어 결과물입니다.

**본인 역할:** 발표자료 3·4·10쪽에 실행 환경 테스트, 반복 디버깅, 해상도·처리속도 조정, 발표자료 제작 담당으로 기록되어 있습니다. 코드 기준 분담에는 `IMGSZ`, `CAP_DSHOW`, 전체화면 관련 설정이 지정되어 있습니다.

```python
IMGSZ = 320
cap = cv2.VideoCapture(0, cv2.CAP_DSHOW)
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 640)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 480)

WIN = 'trash detector'
cv2.namedWindow(WIN, cv2.WND_PROP_FULLSCREEN)
cv2.setWindowProperty(WIN, cv2.WND_PROP_FULLSCREEN,
                      cv2.WINDOW_FULLSCREEN)
```

**문제와 조정:** 기존 발표자료에는 기본 설정에서 화면 처리가 느렸고 입력 크기를 조정한 뒤 체감 동작이 개선됐다고 기록되어 있습니다. 원본 코드는 카메라 해상도를 640×480으로 요청하고, 추론 입력 크기를 320으로 지정합니다. Windows 카메라 백엔드와 전체화면 표시도 설정했습니다.

**기술적으로 구분한 점:** 카메라에서 받는 프레임 크기와 모델에 넣는 입력 크기는 다른 설정입니다. 원본에는 설정값과 정성적 개선 기록이 있으며, 하드웨어가 실제로 적용한 해상도 측정이나 FPS 전후 수치는 없습니다. 따라서 특정 배수의 속도 향상으로 환산하지 않았습니다.

**결과와 경험:** 모델 자체를 교체하는 것 외에도 입력 크기, 카메라 초기화 방식, 출력 창 설정이 시연 경험에 영향을 준다는 점을 다룬 활동입니다. 모델 로드·객체 순회는 송지율, 분류 기준·매핑은 노문선의 역할로 구분했습니다.

증빙: [원본 project.py](../evidence/ai-recycling/project.py), [발표자료의 개인 역할·코드 설명](../evidence/ai-recycling/source-excerpts.md), [프로젝트 전체 설명](../projects/ai-recycling-assistant.md)

## 2. 청주 안심동선 · 지도 화면 구성 기획

**활동 범위:** AI 기반 고령보행자 위험예측과 시설 개선 우선순위를 제안한 팀 기획·설계 경험입니다.

**제안서상 본인 역할:** 17쪽에 프론트엔드·지도 시각화 담당으로 지도 대시보드, 화면 구성, 발표자료 시각화가 기록되어 있습니다.

**관련 팀 산출물:** 제안서 11쪽은 위험도 지도, CCTV 레이어, 정비사업 구역, TOP 20 개선 후보를 함께 보여 주는 화면 구성안입니다. 위험점수만 표시하지 않고 원인과 개선 후보를 연결하는 화면을 제안했습니다.

이 자료는 화면과 정보 구조에 관한 설계 경험을 보여 줍니다. 실제 지도 서비스 배포나 청주시 데이터 분석을 완료했다는 의미는 아닙니다.

증빙: [원본 11·17쪽을 포함한 발췌 PDF](../evidence/cheongju/source-pages.pdf), [공동 기획 설명](../projects/cheongju-safe-route.md)

## 3. AgentBridge · 이번 공모전 참여

2026년 9월 3일 제출된 팀 개발기획서에 AI·SW 분야 팀원으로 기재되어 있습니다. 프로젝트는 자연어 목적 입력, 6개 도구 추천, 운영체제별 설치 안내와 데모를 다룹니다.

현재 신청서에는 개인이 작성한 파일이나 함수까지 구분되어 있지 않습니다. 이 항목은 신청 분야와 팀 프로젝트 참여 기록으로 제시하고, 개인 개발 역량의 구체적 사례는 위 AI 분리배출 도우미 코드 분담으로 연결했습니다.
