# 송성재 · 개인 프로젝트 포트폴리오

인천전자마이스터고등학교 인공지능전자과 2학년 · innovation 팀원

기존 팀 프로젝트에서 문제를 설명하고 제안서의 흐름과 정책 연계, 발표·검증을 준비하는 기획 역할을 맡았습니다. 이번 AgentBridge의 신청 분야는 UI/UX입니다.

## 1. 청주 안심동선 · 문제 정의와 제안서·발표 기획

**프로젝트:** 청주시 원도심의 고령보행자 안전을 주제로, 공공데이터 기반 위험예측과 도시안전시설 개선 우선순위를 제안한 팀 활동입니다. 송지율·황재찬·김건우·송성재가 함께했습니다.

**본인 역할의 근거:** 원본 제안서 17쪽에 송성재의 담당 분야가 “기획 / 발표·검증”, 담당 내용이 “제안서 구조, 정책 연계, 발표 및 질의응답 준비”로 기록되어 있습니다.

| 담당 분야 | 제안서에 담긴 관련 구성 | 원본 위치 |
|---|---|---|
| 문제와 대상 정리 | 원도심·정비사업 주변 생활도로와 고령보행자 문제를 특정 | 4·5쪽 |
| 제안서 구조 | 데이터 수집부터 위험예측, 개선 후보, 보고서까지 설명 | 6쪽 |
| 정책 연계 | 정비사업·기존 CCTV·가로등 활용과 개선 우선순위 연결 | 9·10쪽 |
| 발표·검증 기획 | 모의값의 표시, 4주 추진 계획, 현장확인과 AI 보조 원칙 | 12·14·15쪽 |

**기획에서 다룬 문제:** 위험한 곳을 표시하는 데서 끝나면 담당자가 다음 행동을 정하기 어렵습니다. 팀 제안서는 위험 원인, 기존 시설 활용 여부, 개선 후보와 예산을 함께 보여 주는 흐름으로 구성했습니다. 이 자료를 통해 기술 설명을 사용자의 판단 과정과 연결하는 기획 경험을 제시합니다.

**개인 역할과 공동 산출물:** 제안서의 개인 역할표를 근거로 기획·발표 준비 담당을 기재했습니다. 각 슬라이드 전체의 단독 저작이나 실제 심사 발표 완료를 뜻하지 않습니다.

**활동 범위:** 확인된 결과물은 설계 제안서와 역할 기록입니다. 위험점수·개선효과·5,000만원 예산은 모의 구성이고, 실제 정책 채택·사고 감소·수상 실적은 포함하지 않습니다.

## 2. AgentBridge · UI/UX 분야 참여

2026년 9월 3일 제출된 팀 개발기획서에 UI/UX 분야 팀원으로 기록되어 있습니다. 프로젝트의 사용자는 AI 에이전트를 처음 사용하는 학생·비전공자이며, 쉬운 모드와 고급 모드, 추천 이유, 설치 순서와 오류 안내를 제공하는 팀 작업입니다.

기존 활동의 문제 정의와 정보 구조 기획 경험을 이번 참여 분야와 함께 제시합니다. 제출 문서에는 송지율과 송성재 사이의 세부 화면 분담이나 개인 디자인 원본까지 기재되어 있지 않아 이를 임의로 정하지 않았습니다.

증빙: [AgentBridge 설명과 원본 자료](../projects/agentbridge.md)

## 경험에서 확인할 역량

| 영역 | 현재 자료가 보여 주는 내용 |
|---|---|
| 문제 정의 | 적용 지역·사용자·현장 문제를 좁혀 제안하는 팀 기획 참여 |
| 정보 구조 | 배경·기능·효과·실현 계획을 이어 설명하는 구성 |
| 사용자 관점 | 위험점수와 함께 원인·개선 후보를 제시하는 기획 |
| 검증 관점 | 모의값·계획·현장확인을 구분하는 발표 및 검증 준비 역할 |

현재 포트폴리오는 확인 가능한 기획 경험을 중심으로 작성했습니다. 개인 구현 코드나 디자인 파일이 확인되지 않은 부분을 완료 실적으로 늘려 쓰지 않았습니다.
