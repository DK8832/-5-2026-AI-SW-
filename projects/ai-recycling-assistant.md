# AI 분리배출 도우미 · 이전 개발 경험

2026 SW미래채움 AI·SW 고교 챌린지 피지컬 AI 팀 프로젝트. 당시 GOAT 팀은 노문선·송지율·황재찬으로 구성되었습니다. 이번 innovation 팀 전체가 이 프로젝트를 함께한 것으로 표시하지 않습니다.

## 결과물

사용자가 제공했던 `project4.zip`의 `project.py`를 원본 그대로 수록했습니다. OpenCV 웹캠 프레임을 사전학습 YOLOv8n 모델에 넣고, 클래스별 분리배출 매핑과 신뢰도를 화면에 표시합니다. 사람은 제외하고 매핑표에 없는 클래스는 원래 라벨을 유지합니다.

## 개인별 역할

| 참가자 | 발표자료에 기록된 담당 |
|---|---|
| 송지율 | 모델 로드·웹캠 연동·객체 순회·좌표와 신뢰도 추출·화면 표시 |
| 황재찬 | 실행 환경 테스트·반복 디버깅·해상도 및 입력 크기 조정·발표자료 |
| 노문선 | 분류 기준·TRASH_MAP·EXCLUDE |

## 구현 범위와 기술 설명

- 실제 소스의 카메라 요청 해상도는 640×480, 모델 입력 크기는 320입니다.
- `yolov8n.pt`는 사전학습 모델입니다. 새로 학습한 모델의 정확도 성과로 소개하지 않습니다.
- 신뢰도 퍼센트는 감지 항목별 모델 출력값으로, 데이터셋 전체의 정확도와 다릅니다.
- `TRASH_MAP.get(cls_name, cls_name)`은 미매핑 클래스를 제거하지 않고 원래 이름으로 표시합니다.
- 발표자료에는 정성적 동작 확인 기록이 있지만 정량 FPS·정확도 자료는 없습니다.
- STM32·서보모터를 이용한 자동 분류함은 후속 계획입니다.
